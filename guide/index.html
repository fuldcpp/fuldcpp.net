FulDC++ guide

How to use FulDC++, and what every part of the client actually does.

FulDC++ is a direct connect client for Windows. Direct connect is a file-sharing network built around hubs: a hub is a chat room with a file index attached. You join a hub, you share some folders, and you can search everyone else on that hub and download straight from them — no central server holds the files, and there are no trackers or torrents involved.

If you have used AirDC++, StrongDC++ or DC++ before, everything here will look familiar; FulDC++ is built on the AirDC++ core and adds a true dark theme, rich-text chat, an in-client browser and a pile of quality-of-life features. If you have never used a direct connect client at all, start at Getting started and read straight through — the first four chapters are enough to be up and downloading.

In a hurry? Install, run the setup wizard, open View → Public hubs, double-click a hub, then press Ctrl+S to search. That is the whole thing in one line; the rest of this guide explains the parts.

Conventions used here

File → Settings

A path in bold like this is a menu route: open the File menu, then choose Settings. Settings pages are written the same way, for example Settings → Sharing → Hashing.

Ctrl+S

Keys to press. Where a shortcut exists it is given next to the menu route.

FulDC++ only

Features marked this way do not exist in AirDC++ or DC++ — they are specific to FulDC++, which is usually why they are not documented anywhere else.

This guide describes FulDC++ on Windows 10 and 11. Something missing or wrong? The community discussions are the place to say so.
