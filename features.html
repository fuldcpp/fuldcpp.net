Features

FulDC++ is a full DC client — ADC and NMDC, TLS transfers, segmented downloading, autosearch and an optional Web UI. Below are the additions that set it apart from stock AirDC++.

Look & feel

Your language, applied instantly

18 translations ship with the client, and picking one under Settings → General takes effect the moment you press OK — the menu bar, toolbars, tabs, list headings and the buttons, labels and dropdowns inside every open window, plus the chat and log lines already on screen. No restart.

Full independent dark theme

Dark title bars, menus, scrollbars, list/tree chrome, chat and status bar — independent of the OS theme. 52 colour presets, a custom palette editor, follow-OS option and per-hub tab colours. Toggles live with no restart.

GUI modernization

Inline chat find bar (F3), resizable dialogs, TaskDialog prompts, a recent-hubs dropdown, quick-connect speed-pane sparklines and an Aero connect wizard.

Status-bar enhancements

Clickable Slots/Queued panes, show/hide panels from a right-click menu, plus shared-files, favourites-online and refresh-status panels.

Vertical tabs & chat autocomplete

Optional vertical tab strip, per-hub tab colouring, and a slash-command autocomplete popup in chat.

Modern chat

Multiple emoticon packs with animated GIF emoticons, BBCode rendering for incoming messages, and an optional formatting toolbar.

Rich text chat on ADC hubs

Headings, bold, italic, strikethrough, inline code and code blocks, quotes, lists, links and inline pictures, using the ADC RTF0 extension. A Markdown composer with a live preview, formatting buttons that toggle rather than nest, and attachments inserted as named links. It is only sent where it will be understood — the hub has to offer it, and a private message also needs the other client to say it can show it — and the whole feature can be switched off.

GIF search in chat

A button beside the chat input (or /gif) opens a searchable GIF library with trending suggestions, search-as-you-type and a resizable window.

Favorite hubs & Window menu

Overhauled Favorite Hubs window with filter bar, status bar, last-connected info and drag-drop reordering; connect a whole favorite group at once; expanded Window menu.

Chat background pictures

Put a picture behind the chat text — pick the image, how it is placed and how strongly it shows through — and a FulDC++ picture sits behind the main window by default. Text stays readable over it rather than sitting on a solid block of colour.

Settings that fit, and a search box

The Settings window can be resized, always opens on the screen, and has a search box that narrows every category at once. A ribbon of category icons replaces the old tree, and the page area fills the window.

A toolbar you can rearrange

Customise the toolbar in place by drag and drop, reset it to default in one click, and add your own shortcut buttons to any program. Icon size changes apply as soon as Settings closes. Every icon in the client was redrawn in a flat style.

Built for scaled displays

Emoticons, the chat input buttons and the emoticon picker follow the display scale rather than staying at their unscaled size, and popups ask the monitor they are on. The userlist can also sit on the left of hub windows instead of the right.

Power features

Runs side-by-side with AirDC++

Its own instance identity and profile folders, with a one-time automatic import of an existing AirDC++ profile. Install it without disturbing your current setup.

Native DCAPI plugins

DC++ native C-ABI plugin support (DCAPI v8) — all 10 interfaces and 26 hooks, with a Plugins menu and settings page.

Chat triggers

Keyword / regex chat automation with capture groups $1–$9, away-only mode, fire statistics and import/export.

Auto-recovery & crash supervisor

A watchdog automatically restarts FulDC++ if it crashes or stops responding, including a freeze watchdog for hangs.

Automatic away mode

Set away when the computer is locked, when a full-screen app is running, when the window is minimized, or after inactivity — each with its own optional away message. Manual toggling always wins.

Group users by type

Hub user lists grouped into Ops / Bots / Users with live header counts.

Self-updating GeoIP

IP geolocation using MaxMind GeoLite2 data with a configurable update URL, expiry and a validated staged swap. Dedicated GeoIP settings page.

"Only secure hubs" search & pause-all

A quick-select search filter for hubs with secure transfers, and a one-click pause-all-downloads toolbar action.

Streaming & casting

Play releases while they're still downloading (seek-ahead buffering, subtitle prefetch, resume), and cast what you're watching to DLNA renderers — smart TVs and media boxes — on your network. foobar2000 and other media players are supported.

Backup & restore

AES-256-encrypted configuration backups covering settings, favourites, themes, certificates, Notepad and (opt-in) logs, with automatic/pre-update triggers and a selective restore dialog.

Built-in web browser

Browse the web in a tab inside the client — navigation toolbar, address bar, favourites & history with an organize dialog, its own settings page, "Open in internal browser" on chat links, and downloads that follow your download settings.

Plugins, found and installed from inside the client

Settings → Plugins → "Get plugins…" lists what is available, shows which are installed or need updating, and installs with one click. The list is signed with the FulDC++ release key and every download is checked against the hash it pins, so a tampered plugin is refused. The list is cached, so the dialog opens instantly and still works offline. Available plugins.

Web extensions

Node.js extensions on the AirDC++ extension API, run by the built-in web server and installed from a signed catalogue hosted by FulDC++ itself — or straight from a package file on disk. Each package is verified against the SHA-512 the catalogue publishes. Available extensions.

Public Hubs, merged and filtered

"Merge all" fetches every configured hub list and combines them into one view with duplicates collapsed; the filter narrows as you type; and Public Hubs can ask the users on your connected hubs which hubs they recommend. The Connect button has a drop-down for switching list.

Search Spy

See what is being searched for on your hubs: who searched, the last few seekers per term, their IP where known, which hub it came from and how often it has been seen.

Share profiles on NMDC hubs

The profile picker in the favorite hub properties now works for every hub address, not just ADC, and the chosen profile controls what that hub sees.

Online identities

Publish your accounts on other services (Settings → General) so people on the same hub can find you elsewhere, and see what others publish in a userlist column. Nothing is published unless you fill it in.

A web interface that keeps up

The bundled web interface is FulDC++-branded, can send and receive rich text the same way the client does, tells you whether a given private conversation will actually carry it, and hides the pages a given backend does not implement instead of failing on them.

Start with Windows

Optionally launch FulDC++ automatically on login, with a configurable delay.

Security & protocol robustness

Crash-safe config & recovery

Corrupt local state is quarantined and recovered from rotating .bak copies instead of being discarded, settings are written atomically, and a startup recovery prompt can repair the hash database or restore a backup after a crash — with recovery tools on the Auto-Recovery settings page.

Download scanning

Completed downloads can be scanned automatically with Windows Defender and quarantined if a threat is found — configurable on a dedicated Scanning settings page.

Hardened networking

Rejection of spoofed UDP packets, side-by-side port-hijack protection, and a one-click dialog to re-pin a changed TLS keyprint.

Protocol gap fixes

IPv6 on NMDC hubs (the "IP64" extension) and nmdcs:// (TLS) hubs, plus ADC additions (failover, RDEX, passive PSR relay and more) and NMDC additions ($MyINFO server/fireball bits, $NickRule/$SearchRule, TTHS short search, $FailOver, $MCTo, salted-password login, $BotList).

In-client updates

Signed, self-installing updates delivered straight from this site — no manual reinstall. Install with the installer or unzip the portable package; both update the same way.

Open source
